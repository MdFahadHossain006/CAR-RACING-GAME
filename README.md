## 🎮 Overview

**Custom Driver Racing** is an interactive, browser-based racing game where players can **enter their own name** and compete for the highest score. Built with vanilla HTML5, CSS3 (Glassmorphism), and JavaScript — no external libraries or frameworks. The game features smooth animations, dynamic difficulty, and a premium glassmorphic user interface.

## ✨ Features

- 🏎️ **Custom Driver Name** – Enter any name (up to 16 chars) that appears on the car and scoreboard.
- 🥇 **High Score Saving** – Your best score is stored locally using `localStorage`.
- 🚗 **Smooth Racing Mechanics** – 3-lane highway, enemy cars, speed increases with score.
- 🎨 **Premium Glass UI** – Frosted glass panels, glowing borders, dynamic lighting.
- 📱 **Responsive Controls** – Keyboard (← → / A D) + on-screen buttons for touch devices.
- 🧠 **Adaptive Difficulty** – Game speed and enemy spawn rates increase as you progress.


---

## 🕹️ How to Play

1. **Enter your name** in the input field and click "SET DRIVER".
2. Use **LEFT / RIGHT arrow keys** (or A/D) to switch lanes.
3. Avoid **red enemy cars** – each collision ends the game.
4. Every enemy that safely passes below the screen adds **+11 points**.
5. The game gets faster as your score increases – stay focused!
6. Press **RESTART** after Game Over to try again.
